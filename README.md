# 兰洋科技 × scroll-world 概念原型

这是一版不调用付费视频模型的静帧验证稿。它复用了 `scroll-world` 的配置式滚动引擎，验证兰洋科技面向算力中心与新能源行业的液冷业务，能否被组织成一个连续的工业品牌世界。

## 当前叙事结构

1. 算力热密度：高密度 AI 算力带来的散热挑战
2. 芯片冷板：微流道冷板、供回液与 CDU 的间接液冷闭环
3. 机柜浸没：2U 与 GPU 服务器的直接液冷路径
4. 液冷基础设施：一次侧、二次侧、泵组、换热与 PLC 控制
5. 新能源热管理：动力电池与储能电池的液冷温控
6. 规模化交付：制造、测试、项目部署与内容转化入口

公众号和视频号只承担技术解读、案例传播与品牌转化，不再作为一段独立的主营业务场景。

事实信息与品牌素材取自[兰洋科技官网](https://www.blueocean-china.net/)。两个微信二维码来自官网页脚；视频号没有公开网页链接，因此目前只保留待接入入口，不使用虚假地址。

## 预览

直接用现代浏览器打开 `index.html`，或在本目录启动任意静态文件服务器。当前版本只有静帧，因此不依赖 HTTP Range。

## 升级为完整 scroll-world

完整版本需要为 6 个场景生成镜头片段，并按实际渲染帧制作无缝连接片：

- 桌面链：6 段场景视频 + 5 段连接视频
- 移动链：若需要原生 9:16，需要再生成一套 11 段视频
- 连接片必须使用相邻视频的真实末帧和首帧，否则会出现跳帧
- 生成前需要明确镜头运动、桌面与移动画幅、生成平台和预算

当前静帧版适合先确认内容顺序、工业视觉语言、标题语气、业务转化入口与移动端阅读密度。

## 仍需补充的真实素材

- 公众号代表文章 6–12 篇及其永久链接
- 视频号代表视频 3–6 条的分享链接或二维码
- 优先转化的产品线和商务合作入口
- 品牌手册、标准色、字体以及可公开使用的产品与项目照片
